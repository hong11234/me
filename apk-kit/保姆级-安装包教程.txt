把小月亮 / 生活记 做成安卓安装包（APK）
保姆级教程 · 零基础版
==========================================

先回答你最关心的三个问题：

Q1：要花钱吗？
A：不要。全程免费。

Q2：要装什么软件吗？
A：不用装任何软件。你只需要打开两个"网站"，在网页上点几下。

Q3：最后得到的是网页还是 App？
A：最后下载到一个 .apk 文件，装到手机上，
   会有图标、出现在应用列表里、打开是全屏，
   和你在应用商店下载的 App 一模一样。


==========================================
准备工作（5 分钟）
==========================================

需要：
  · 一台能上网的电脑（Windows 就行，不用装东西）
  · 一个能收邮件的邮箱（QQ 邮箱就行）
  · 30 分钟

把「小月亮+生活记-APK打包材料.zip」拷到电脑上，
右键 → 解压到当前文件夹。
解压后会看到两个文件夹：moon 和 life。

  moon = 小月亮
  life = 生活记


==========================================
第一步：注册 GitHub（8 分钟）
==========================================

GitHub 是什么？简单说：一个免费放网页的地方。
我们把文件放上去，它会给我们一个网址，后面打包要用。

1. 打开浏览器（Edge 或 Chrome）
2. 地址栏输入：github.com  回车
3. 点右上角「Sign up」（注册）
4. 按提示填：
   · 邮箱（QQ 邮箱就行）
   · 密码（8 位以上，要有字母和数字）
   · 用户名（随便起，比如 xiaoyueliang2026，只能用英文数字）
5. 会给你发一封邮件，里面是 6 位数字验证码，
   去邮箱找到它，填进去
6. 后面如果问 "How many team members..."，随便选一个
   "Just me" / "Skip"，一路点 Continue / Skip 到底

完成后你会进入一个叫 Dashboard 的页面，全是英文，别慌。

【英文单词对照表】
  Sign up / Sign in  = 注册 / 登录
  Create repository  = 创建仓库（就是建一个文件夹）
  Public / Private   = 公开 / 私有（选 Public）
  Upload files       = 上传文件
  Commit changes     = 确认提交
  Settings           = 设置
  Pages              = 页面（这里开启网站）
  Branch             = 分支（选 main）
  Save               = 保存


==========================================
第二步：建一个"仓库"（3 分钟）
==========================================

1. 登录后，点右上角「+」号 → 选「New repository」
2. 页面里有两个输入框：
   · Repository name：填  my-apps
   · 下面选「Public」（公开）
3. 最下面绿色按钮「Create repository」，点它


==========================================
第三步：把两个文件夹传上去（5 分钟）
==========================================

1. 在新页面中间，有一行字「uploading an existing file」，
   点它（或者点「Add file」→「Upload files」）
2. 出现一个虚线大框，写着 "Drag files here"
3. 打开你解压出来的文件夹，把 **moon 和 life 这两个文件夹**
   一起拖进那个大框里
   （注意：拖文件夹本身，不是拖里面的文件）
4. 等进度条跑完（文件很小，几秒）
5. 拉到页面最下面，点绿色按钮「Commit changes」

完成后的页面应该长这样：
  my-apps
    life/
    moon/


==========================================
第四步：开启网站（3 分钟）
==========================================

1. 在仓库页面上方，点「Settings」（齿轮图标）
2. 左边竖排菜单里，往下找，点「Pages」
3. 在 "Branch" 那里：
   · 左边下拉选 main
   · 右边保持 / (root)
   · 点「Save」
4. 等 1～2 分钟，刷新这个页面
5. 上方会出现一行字：
   "Your site is live at https://你的用户名.github.io/my-apps/"
   这就是你的网址

测试一下：在浏览器打开
   https://你的用户名.github.io/my-apps/life/
   https://你的用户名.github.io/my-apps/moon/

能看到应用界面 = 成功。
（第一次可能要点一下刷新）


==========================================
第五步：打包成 APK（5 分钟）
==========================================

1. 打开新标签页，地址栏输入：pwabuilder.com
2. 页面中间有个输入框，把刚才的网址粘进去：
   https://你的用户名.github.io/my-apps/life/
3. 点「Start」
4. 等它检测（转圈 10 秒左右），出现一个评分页面
5. 点「Package for stores」（打包）
6. 里面选「Android」
7. 点「Generate」/「Download」，会下载一个 .zip 文件
8. 解压这个 zip，里面有一个 .apk 文件 → 这就是安装包！

想要小月亮的，就把第 2 步的网址换成 moon 那个，重复一遍。


==========================================
第六步：装到手机上（2 分钟）
==========================================

1. 把 .apk 文件发到手机（微信文件传输助手）
2. 手机上点开这个文件
3. 手机会提示「未知来源应用」→ 点「允许」/「设置」→ 打开开关
4. 点「安装」
5. 桌面上出现图标，点开就是 App


==========================================
常见问题
==========================================

Q：GitHub 打不开 / 一直转圈？
A：换个网络（手机热点试试）。还不行就用国内的 gitee.com，
   注册和上传类似；拿到 gitee 的网址后，
   PWABuilder 一般也能用（不行就在 PWABuilder 里选 "Enter URL manually"）。

Q：上传的时候提示文件太大？
A：不会，我们的文件一共才 200KB 左右。

Q：Pages 里没有 Save 按钮？
A：确认 Branch 选了 main；没看到 main 就说明第一步上传没成功，回去重传。

Q：网址打开是 404？
A：等 1 分钟再刷新。还不行检查文件夹名是不是 life / moon（小写）。

Q：PWABuilder 说 "not a valid PWA"？
A：说明网址打开不正常，或者 manifest.json 没上传。
   先确认浏览器能打开 https://.../life/ 并且显示应用界面。

Q：装好的 App 打开是白屏？
A：第一次打开需要联网加载一次，之后就离线可用。
   还不行就检查网址能不能打开。

Q：App 上面有一条地址栏？
A：正常现象，不影响使用。要完全全屏需要额外配置，可以忽略。

Q：之前浏览器里的数据能搬过去吗？
A：能。在旧浏览器里「设置 → 导出备份」，得到 .json 文件；
   在 App 里「设置 → 导入备份」选它。
   注意：会覆盖 App 里已有的数据。
